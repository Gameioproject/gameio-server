What it is

The whole catalog

Every system from the NES to the PS3, in one place, sorted and searchable. You are not limited to what is already on the device.

Built for a controller

No touchscreen required. Sticks, D-pad and shoulder buttons move through everything, including the keyboard.

Saves follow you

Battery saves sync to the server as you play, so picking a game back up on another device starts where you left off.

Installing

Download the APK using the button above. On a handheld, open this page in its own browser so the file lands on the device.

Open it. Android will ask to allow installs from this source the first time. That prompt is normal for an app that does not come from the Play Store.

Launch Gameio and enter this server's address: playgameio.com

Sign in with the username and password you were given. That is all the setup there is.

Do not have an account yet? Accounts are created by whoever runs this server. Ask them for a username and password.
