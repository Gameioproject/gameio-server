What it is

You are not browsing what you
remembered to copy across.

Gameio points at a server that holds the catalog, not the files. Every console it knows about shows up as shelves you scroll, the same way you would scroll a streaming app, and a game only lands on the device when you ask for it.

Browse, don't manage

Shelves, search across the whole server, and A to Z jumps. No folders, no scraping, no copying files onto an SD card before you can see what you have.

Built for a controller

Sticks, D-pad and shoulder buttons drive everything, down to the on-screen keyboard. Nothing here waits for you to reach for a touchscreen.

Saves travel with you

Battery saves sync to the server while you play, so the next device you pick up starts where the last one stopped.

Getting on

Three things, then you're playing.

01

02

Username and password, the ones whoever runs the server gave you. That is the whole setup.
