What it is

You are not browsing what you remembered to copy across.

Every console the server knows about shows up as shelves you scroll, the same way you would scroll a streaming app. No folders, no scraping, no SD card to fill before you can see what you have.

Browse, don't manage

Shelves, search across the whole server, and A to Z jumps. Pick something, and it downloads while you keep looking.

Built for a controller

Sticks, D-pad and shoulder buttons drive everything, down to the on-screen keyboard. Nothing here waits for you to reach for a touchscreen.

Saves travel with you

Battery saves and save states sync to the server while you play, so the next device you pick up starts where the last one stopped.

Getting on

Three things, then you're playing.

1

Install it

Download the APK and open it. Android asks to allow installs from this source the first time, which is normal outside the Play Store.

2

Point it at the server

Enter playgameio.com when it asks for an address.

3

Sign in

Username and password, the ones whoever runs the server gave you. That is the whole setup.

Put your library on the handheld.

One APK. No account to create here, no store to go through.
